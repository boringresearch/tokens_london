Project description
NVIDIA VSS watches the same video. Its Long Video Summarization API returns events with start and end times. Replica maps each timestamp to a frame, looks up the camera pose it solved for that frame, and drops a pin in the 3D viewer. Click a pin and the camera flies to where it was filmed. VSS Q&A answers are parsed for times and pinned the same way.
Clips are passed to VSS as URLs from a VAST Data bucket behind an https allowlist, so footage never round-trips through the app. The VSS Alert Agent on live RTSP streams, so incidents land on the map in real time.
