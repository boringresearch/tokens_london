Project description
vgrep is a command-line tool for searching video footage with natural-language queries. It indexes local video, then returns matching clips with timestamps and short descriptions. You can also search using an example image or clip.
The project combines text and visual search, then checks candidate results before displaying them. It supports filters such as camera and time range, and can show why a result matched. A fully offline demo uses generated synthetic footage and fake backends; real video search needs a configured embedder and verifier. Optional remote backends include CLIP embeddings, YOLO11 object detection, and Cosmos Reason captioning and verification. vgrep searches actions and objects, and does not identify people or faces.
