Project description
Omda is a real restaurant. Friday lunch, six cameras, five minutes, 350 clips nobody has time to watch. Ask Omda answers questions about the floor and cites the moments it used: “Did anyone leave without paying?”, “Deleveroo says rider D6 was late, whose fault was it?”, “What would you flag to the owner?” It works by text or voice over any 5-minute, 30-minute or 1-hour window.
It does three things a human can’t do at lunch rush. Dine-and-dash detection: a party finishes, stands and exits; Omda checks the till camera in between and finds no payment. Delivery dispute resolution: a door-to-counter-to-door timeline for every rider, so the kitchen stops eating refunds it didn’t cause. Owner’s briefing: an auto-written report of bottlenecks, waits and anomalies, each point linked to a clip.
Every 5-second clip is described by NVIDIA Cosmos Reason, counted by YOLO11 and embedded with Cosmos Embed1, then indexed in VastDB via VAST DataEngine. Our Floor Twin tracker (DGX Spark) gives customers, staff and riders stable IDs, so the agent can stitch one person across rooms and one moment across cameras. Reasoning runs on DeepSeek via W&B Inference; every answer is traced and scored in Weave against ground-truth and adversarial questions, so it cites or says it doesn’t know. Built with Cursor on the VAST workshop skills.
