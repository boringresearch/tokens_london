Project description
Scene2Real aims to save lives by turning warehouse fire footage into robot response rehearsals before physical deployment.
NVIDIA Cosmos, served through CoreWeave, analyses incident footage and extracts timestamped fire evidence. An operator reviews the findings, confirms a response target and maps it to an authored warehouse zone.
The app builds a parameterised MuJoCo scene and validates a constrained robot plan before execution. The robot rehearses the response while the simulator measures aiming error, unintended collisions and duration. Teams can reset and replay the scene, with each result linked to the original footage and explicit scene assumptions.
