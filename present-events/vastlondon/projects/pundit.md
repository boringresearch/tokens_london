Project description
Somebody wants to ask questions about the items, activities, and scenes appearing in a video.
The user uploads a video using an interactive web page (plus chrome extension)  to VAST, which is analysed using an LLM running on Coreweave to create a description of short segments and a timeline of the start of each scene.
Clicking on the generated timeline brings up a summary of the items appearing in the scene, plus wikipedia links.
This all combines to create an interactive experience for viewers watching videos with amazing overlays.
