Project description
RecallAI is a memory layer for smart AI. A phone camera, or glasses, watches wearer's day, keeps only moments that matter, and turns them into structured memory.
Capture and filter -> perceive using VLM -> remember using object events -> reason using agent -> prove answers using frames relied on.
NVIDIA used for perception step with Nemotron VLM core of system.
Cursor used to develop in IDE.
CoreWeave and Weights and Biases calls run on serverless inference, and powered by GPUs.
