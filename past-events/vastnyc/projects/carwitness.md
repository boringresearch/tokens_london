Project description
CarWitness (车证) is "Ctrl+F for street cameras." A live event feed flags vehicle events across every camera, and anyone can ask in English or Chinese to get matching clips with NVIDIA Cosmos descriptions, YOLO11 detections and playable video. A language model on W&B Inference plans each search. Selected clips become a bilingual incident report where every finding cites a clip timestamp and unsupported findings are dropped, and any clip can be exported as an AV-simulation scene card. The UI switches between English and Chinese.
