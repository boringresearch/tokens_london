Project description
SafeRoute is an AI-powered evacuation planning prototype that demonstrates how street-camera evidence can inform routing during disasters. It combines real archived NYC footage with simulated wildfire and hurricane effects, uses NVIDIA Cosmos to assess visible road conditions, and calculates routes around blocked or potentially dangerous intersections. Built with VAST’s video archive and W&B inference and tracing, it provides an interactive map, evolving disaster scenarios, and plain-language route briefings. The project is an evacuation drill, not a live emergency navigation system
