Project description
An application that uses VAST video data to identify any clips where broken asphalt, blocked bike lanes, broken streets, potholes, or damaging areas potentially for cyclists exist. The goal would be to gather a confidence score from users on how many people requested a fix for these areas, looking for a time interval between the complaints and notifying both ends to see if any users raise the confidence score high enough for the DOT to receive a message. When the process is completed, both the users and the offices both receive messages that the problem has been resolved.
