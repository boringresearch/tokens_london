Project description
StreetStyle Scout makes street footage searchable by visible clothing and colors. Users enter a plain-language query, browse matching frames, and play the source video to check the result. VAST provides video retrieval, YOLO locates people, and NVIDIA Cosmos analyzes visible clothing. The workshop’s models run on CoreWeave GPUs. Cursor assisted backend development, and Claude Code built the frontend. Results separate observed details from uncertainty and link back to video evidence. The prototype focuses on selected San Francisco clips and requires human review because search relevance is imperfect. It does not identify people, guess clothing brands, or infer citywide trends.
