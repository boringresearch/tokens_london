Project description
A review assistant built on the supplied VSS archive. A reviewer searches indexed footage in plain language and gets ranked evidence cards linked to the source interval. A W&B-hosted LLM assesses each card against a fixed event definition and rule card. The reviewer then records a decision, which is stored separately from the machine assessment.
Live: https://team-6-vss.thecosmoslabs.com/app
