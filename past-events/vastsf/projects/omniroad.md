Project description
We use Nvidia Cosmos reasoner model and YOLO object detection to quickly detect objects. The Cosmos reasoner model then analyses the scene and then reasons out the whole scenario: whether there is a pothole, how deep the pothole is, which vehicle parts can be damaged because of this pothole, etc and then the whole thing is communicated to near by vehicles. We create a memory map of the whole city.
