Project description
We built on the VAST Builders Challenge stack: neighborhood and street cameras already indexed in our team VSS archive. Search uses Cosmos Embed hybrid retrieval over segment captions; Cosmos Reason supplies the descriptions we search and summarize; YOLO detections help filter vehicle-related moments. Cursor skills drove login, search, agent Q&A, and optional re-ingest when we needed captions tuned to parked cars and curb activity. App logic runs on top of the VSS APIs so the demo is search → evidence clip → answer, not a rebuilt ingest pipeline.
