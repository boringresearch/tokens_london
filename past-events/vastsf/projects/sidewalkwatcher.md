Project description
Sidewalk Watch uses street-level video to automatically detect temporary sidewalk obstructions that can create accessibility barriers, such as parked vehicles, construction equipment, trash bins, and other objects blocking pedestrian paths. The system analyzes video segments using computer vision and video-reasoning models, identifies potential obstructions, and attaches location and timestamp information so barriers can be mapped and reviewed. The goal is to complement projects like Project Sidewalk by detecting what is blocking a sidewalk right now, rather than primarily documenting permanent accessibility infrastructure.
